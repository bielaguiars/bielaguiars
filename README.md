## 📌 Projetos em destaque

### 🚗 VelozCar — Sistema de Locadora de Veículos

Projeto acadêmico de banco de dados para uma locadora de veículos, com modelagem relacional, consultas SQL e análise de indicadores como faturamento, pagamentos, veículos mais alugados, manutenções e produtividade de funcionários.

**Tecnologias utilizadas:** SQL, MySQL/MariaDB, modelagem de dados e análise de indicadores.

---

### 🔗 Atividade de Grafos

Projeto acadêmico desenvolvido na disciplina de Teoria dos Grafos, com implementação de algoritmos em Java para estudo de buscas, caminhos mínimos, fluxo e estruturas de grafos.

**Tecnologias utilizadas:** Java e conceitos de Teoria dos Grafos.

---

### 🏠 Sistema Imobiliário

Projeto de estudo voltado para modelagem de clientes, imóveis e transações, utilizando banco de dados relacional e consultas SQL para representar operações do mercado imobiliário.

**Tecnologias utilizadas:** SQL, modelagem relacional e banco de dados.

---

### 📊 Análise de Dados

Projetos e estudos práticos envolvendo tratamento de dados, consultas SQL, visualização de informações e construção de insights para apoiar decisões.

**Tecnologias utilizadas:** Python, SQL, Power BI, Pandas e Google Colab.
